# 지역현황 핵심 관광지표 API 연결 구현 계획

## 적용 범위

- 지역현황 페이지의 `핵심 관광지표` 영역에만 새 화면을 연결한다.
- 정책 시뮬레이션에서도 사용하는 기존 `KpiGrid`는 수정하지 않는다.
- 제목·부제목·지역 내 비교 선택은 추가하지 않는다. 전국에서 자료가 관측된 시군구를 비교한다.
- 기존 방문 추정치 월 합계도 같은 영역 안에 보존한다.

## 화면과 동작

1. 최초 화면에는 체류 강도·소비 강도·서비스 수요의 전국 순위와 순위 위치 그래프를 표시한다.
2. 선택한 카드를 왼쪽의 넓은 상세 영역으로 확장하고, 나머지는 오른쪽에 모은다. 모바일에서는 상세 아래에 나머지를 배치한다.
3. 상세에는 현재 지역 지수, 비교 지역 평균·중앙값, 각각의 차이, 하위 지수 5·3·12개를 표시한다.
4. 항목 앞의 옅은 9px 정보 아이콘을 누르면 말풍선을 표시한다. 바깥 클릭·Esc·닫기 버튼으로 닫고, 키보드 조작과 모바일 터치를 지원한다.
5. 공통 스타일에 영향을 주지 않도록 전용 클래스와 스타일 파일로 범위를 제한한다. 일반·다크 테마를 지원한다.

## API 연결 및 계산

- `summary`의 기준월과 현재 지역을 기준으로 `rank`를 지표 코드 21·22·11 각각 조회한다.
- 기존 전국 순위의 비교 집합에 대해 평균(합계/지역 수), 중앙값, 대상 지역 값, 동점 수를 추가 반환한다. 기존 필드는 유지한다.
- 시도 합계는 제외하고 시군구 중복은 제거한다. 누락 때문에 비교가 불완전하면 순위·평균·중앙값을 임의로 계산해 표시하지 않는다.
- 하위 지수는 카드 선택 시 기존 `indices` API로 조회한다. 지역·기준월 변경 시 이전 지역의 선택 상태와 데이터가 남지 않도록 한다.
- HTML 시안의 가상 값은 사용하지 않는다. 오류·로딩·자료 없음은 각각 구분하고 재시도를 제공한다.
- API 키는 기존 서버 처리 경로를 유지한다. 개인정보나 새로운 저장 테이블은 추가하지 않는다.

## 검증

- 평균·중앙값의 홀수/짝수 표본, 동점, 결측·중복·시도 합계 제외를 서버 테스트로 확인한다.
- TypeScript 검사·빌드 및 기존 관련 회귀 테스트를 실행한다.
- 실제 API 응답의 순위·평균·중앙값과 화면 값이 일치하는지 확인한다.
- 브라우저에서 카드 확장·전환·말풍선·모바일 배치를 확인한다.
- 다른 탭이 기존 `KpiGrid`를 계속 사용하고, 지역현황의 다른 구성요소가 바뀌지 않았는지 변경 내역으로 확인한다.

## 이번 단계

이 문서의 한 기능만 구현하고 확인 결과를 전달한다. 이후 다른 탭에 적용하는 작업은 진행하지 않는다.

## 구현 및 검증 결과

- `OverviewPage.tsx`에서 핵심 관광지표를 `OverviewTourismIndicators`로 연결했다. 페이지의 다른 구성요소와 기존 `KpiGrid`는 유지했다.
- `overviewIndicatorDefinitions.ts`는 20개 하위 지수의 코드·이름·설명을 담당한다. `OverviewTourismIndicators.css`는 이 영역만 꾸민다.
- 서버의 기존 순위 응답에 `value`, `mean`, `median`, `tieCount`를 추가했다. 평균과 중앙값은 원자료를 새로 추정하지 않고 실제 관측된 지역별 지수에서 계산한다.
- Python 테스트 103개와 TypeScript/Node 회귀 테스트 89개를 통과했다. 새 테스트는 표본의 홀짝, 동점, 시도 합계 제외, 중복, 결측을 확인한다.
- 프로덕션 빌드 통과. 기존 의존성 주석 및 번들 크기 경고는 남아 있다.
- 광주 동구 2026년 8월 실제 API 확인: 체류 137/256위·평균 75.211875·중앙값 72.54, 소비 187/256위·평균 74.50203125·중앙값 73.04, 서비스 수요 184/259위·평균 약 70.16092664·중앙값 67.64.
- 브라우저에서 실제 순위·하위 지수, 카드 확장, 9px 설명 아이콘, 말풍선, Esc 닫기와 초점 복귀를 확인했다.
- 390px 모바일 화면에서 페이지·컴포넌트의 가로 넘침이 없고, 말풍선이 화면 안에 표시됨을 확인했다.
- 서구로 이동하면 새 데이터가 표시되고 이전 지역 선택이 초기화된다. 정책 시뮬레이션에서는 기존 카드가 유지되고 새 컴포넌트가 0개임을 확인했다.
