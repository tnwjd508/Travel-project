# 관광지표 화면 통일 구현 계획

## 목표와 범위

지역현황에서 승인된 관광 체류 강도·관광 소비 강도·관광 서비스 수요 카드를 정책 시뮬레이션과 AI 보고서의 핵심 지표 영역에도 적용한다. 기존 정책 설정, 진단 결과, 기관 로그인·저장 기능은 유지한다.

## 구현 방식

1. 기존 확장형 카드 컴포넌트가 외부에서 전달받은 요약 데이터를 사용할 수 있도록 공통 진입점을 추가한다.
2. 시뮬레이션에서는 이미 조회한 기준선 요약을 전달해 중복 조회를 피한다. 기관에 저장된 검토를 보는 경우 최신 API를 섞지 않는다.
3. 보고서 미리보기에서도 같은 카드로 순위·평균·중앙값·하위 지수·설명 말풍선을 표시한다.
4. 보고서 생성 시 요약·진단과 함께 세 지표의 비교 통계 및 하위 지수를 복사해 고정한다. 지역 또는 기준월이 다른 응답은 포함하지 않는다.
5. 이전 기관 저장 검토에는 새 비교 자료가 없으므로 없는 항목은 명확하게 안내한다. 저장 스키마나 과거 데이터를 변경하지 않는다.
6. 인쇄 시 접힌 상세를 모두 펼쳐 세 지표를 출력하고, 클릭용 아이콘·말풍선을 제외한다. 저장된 값을 그대로 출력한다.

## 검증

- 보고서 스냅샷의 지역·기준월 확인, 일부 API 실패, 조회 취소, 이후 응답 변경과의 독립성을 테스트한다.
- TypeScript 검사 및 빌드, 관련 회귀 테스트를 실행한다.
- 브라우저에서 시뮬레이션·보고서 카드 확장과 말풍선을 확인한다.
- 보고서 생성 후 새 네트워크 값으로 바뀌지 않는지, 인쇄용 스타일이 접힌 상세까지 표시하는지 확인한다.

## 구현 결과

- `TourismIndicators`를 세 화면에서 함께 사용한다. 외부 `state`를 전달하면 기존 요약 데이터를 사용하며 별도 요약 요청은 하지 않는다.
- `frozen` 상태에서는 순위·하위 지수 API 요청을 중지하고 전달받은 스냅샷만 표시한다. 이전 저장 기록에 없는 비교 값은 현재 값으로 대체하지 않는다.
- `captureIndicatorSnapshot`은 동일 지역·동일 기준월·동일 요약값에 해당하는 응답만 복사한다. 일부 요청이 실패하면 해당 자료만 비워 두고, 취소된 작업은 저장하지 않는다.
- 보고서의 생성 버튼은 이 복사본을 요약·진단과 함께 화면 내 스냅샷으로 고정한다. 기존과 동일하게 이 로컬 보고서는 페이지를 벗어나면 사라지며, 기관 DB 저장 기능은 바꾸지 않았다.
- 인쇄 스타일은 모든 상세 영역을 표시하고 설명 아이콘·말풍선·조작 안내를 숨기도록 추가했다.

## 확인 결과

- TypeScript 검사 및 프로덕션 빌드 통과. 기존 의존성 주석·번들 크기 경고는 남아 있다.
- 회귀 테스트 92개 통과. 스냅샷 관련 새 테스트 3개에서 지역·월·요약값 불일치, 원본 객체 변경, 일부 실패, 취소를 확인했다.
- 실제 시뮬레이션에서 소비 강도 187/256위, 70.32, 평균 74.50, 중앙값 73.04 및 하위 지수를 확인했다.
- 실제 보고서 생성 후 저장 시점 표시, 인쇄 버튼 활성화, 서비스 수요 184/259위, 65.34, 평균 70.16, 중앙값 67.64와 하위 지수 12개가 유지되는 것을 확인했다.
- 기존 정책 설정·기관 저장·진단 결과는 변경하지 않았다. 실제 PDF 파일 저장은 실행하지 않았다.
