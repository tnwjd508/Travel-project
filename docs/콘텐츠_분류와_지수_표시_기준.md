# 콘텐츠 분류와 지수 표시 기준

2026-09-18 반영. API 응답과 계산은 유지하고 화면의 명칭·해석 안내를 보완했다.

## 콘텐츠 분류

`contents.items[].category`와 `typeShare[].category`는 `contentTypeId`가 아닌 `lclsSystm1`이다. [한국관광공사 국문 관광정보](https://www.data.go.kr/data/15101578/openapi.do)의 `KorService2/lclsSystmCode2`를 `lclsSystmListYn=N`으로 조회해 다음 대분류명을 확인했다.

| 코드 | 공식 명칭 |
| --- | --- |
| AC | 숙박 |
| C01 | 추천코스 |
| EV | 축제/공연/행사 |
| EX | 체험관광 |
| FD | 음식 |
| HS | 역사관광 |
| LS | 레저스포츠 |
| NA | 자연관광 |
| SH | 쇼핑 |
| VE | 문화관광 |

차트 툴팁·범례·지도에 동일한 매핑을 적용한다. 미등록 코드와 `unknown`은 ‘분류 정보 없음’으로 표시한다. 구성비는 조회 시점의 해당 분류 등록 콘텐츠 수 / 전체 등록 콘텐츠 수 × 100이다.

## 지수 기준

[한국관광 데이터랩 관광수요 지수](https://datalab.visitkorea.or.kr/datalab/portal/loc/getTourActivateForm.do)의 안내에서 월마다 최소·최대가 다시 산출되며 0~100 고정 범위가 아님을 확인했다. 같은 월·같은 지표·같은 지역 단위로 비교한다. 기준월과 단위, 각 지표의 의미, 인원·금액·비율로 환산할 수 없다는 설명과 원문 링크를 함께 표시한다. 서비스가 세부 표준화 산식이나 기준값을 확보한 것처럼 표기하지 않는다.

[관광 자원 수요 API](https://www.data.go.kr/data/15152138/openapi.do)의 설명에 따라 관광서비스수요는 SNS·관광 소비·목적지 검색, 문화자연자원 수요는 목적지 검색 관련 하위 지표의 평균으로 설명한다.

자체 6축 평균과 `draft-1` 판정 기준은 기존 `backend/diagnosis.py`, `server/diagnosis.ts`의 구현을 그대로 설명한다. 공식 정상 범위로 오해하지 않도록 ‘정상 범위’ 표시를 ‘검토 기준 미해당’으로 바꿨다. 판정 산식과 API 계약은 변경하지 않았다.

적용 화면: 관광 데이터, 핵심 관광 지표, 지역 진단, 보고서(인쇄 포함), 월간 브리핑. 기존 홍보 컴포넌트의 고정 지수는 화면 예시·산출 기준 없음으로 표시한다.

검증: TypeScript·Vite 빌드, 실제 동구 콘텐츠 124건의 분류명, 연령 안내, 지도 명칭, 320/768/1024/1440px에서 지수 안내의 가로 넘침 여부 확인.
